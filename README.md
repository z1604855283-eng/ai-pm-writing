# AI 产品经理写作 Skill。

这是一个面向一线 AI 产品经理的中文专业写作 Skill，用于把零散想法、产品经验和 AI 技术知识整理成专业、好懂、有判断的文章。

## 适用内容

- AI 基础概念与技术科普
- Agent、RAG、Prompt、模型评测等产品化知识
- AI 产品设计与需求分析
- 竞品分析与产品案例拆解
- 数据指标与产品迭代方法
- 真实项目与工作复盘
- AI 行业趋势与新产品解读
- AI 产品经理职业成长

## 核心特点

- 面向 AI／产品新人解释专业概念
- 重点讲清概念关系、形成原因和产品影响
- 观点明确，并用事实、案例和证据支撑
- 长文默认采用总—分—总结构
- 一级标题使用中文序号，长文自动加入目录
- 结尾提供判断标准、步骤、清单或决策边界
- 成稿后附排版建议与配图建议

## Skill 文件

完整 Skill 位于 [ai-pm-writing](./ai-pm-writing/) 目录，其中包含：

- `SKILL.md`：核心执行流程与写作规则
- `references/author-profile.md`：个人作者画像与长期偏好
- `references/ai-pm-style.md`：AI 产品经理文章风格
- `references/article-types.md`：不同文章类型的写作路径
- `references/research-and-evidence.md`：研究与证据规则
- `references/revision-ai-pm.md`：审稿清单
- `scripts/check_ai_pm_prose.py`：文章结构和语言检查脚本

## 使用方式

下载或克隆本仓库，将 `ai-pm-writing` 文件夹作为 Skill 导入支持 Skills 的环境，然后使用 `@ai-pm-writing` 调用。

当前版本：`2.0.0`
